# Calculator CLI App

A simple command-line calculator built in Python as part of the **Python Developer Internship – Task 1** (Elevate Labs).

## Objective
Create a command-line calculator supporting basic arithmetic operations.

## Features
- Addition, Subtraction, Multiplication, Division
- Menu-driven interface that loops until the user chooses to exit
- Input validation (rejects non-numeric input and re-prompts)
- Handles division by zero gracefully

## Tools Used
- Python 3
- VS Code
- Terminal

## How to Run
```bash
python calculator.py
```

Then follow the on-screen menu:
```
===== CALCULATOR MENU =====
1. Add        (+)
2. Subtract   (-)
3. Multiply   (*)
4. Divide     (/)
5. Exit
============================
```

## Key Concepts Practiced
- Functions
- Loops
- Conditionals
- CLI interaction (input/output handling)
